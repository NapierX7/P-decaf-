# Pe de Cafe - Site pronto para Vercel

Site estatico em HTML, CSS e JavaScript. Todas as imagens e a logo SVG estao em assets.

## Publicar pelo terminal

1. Abra esta pasta no terminal.
2. Execute: npx vercel --prod
3. Entre na sua conta e siga as instrucoes.

Configuracao: Framework Preset = Other. Sem Build Command e sem Install Command. Output Directory = .

Para importar pelo painel da Vercel, envie esta pasta a um repositorio GitHub e importe o repositorio em Add New > Project.

O index.html deve ficar na raiz do projeto. Nao precisa de banco de dados ou variaveis de ambiente.
